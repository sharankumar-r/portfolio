# Portfolio — Sharan Kumar R

Personal portfolio website of **Sharan Kumar R**, Computer Science & Engineering undergraduate focusing on full-stack web development and cybersecurity.

## Live Preview
Deployable via [GitHub Pages](https://pages.github.com/).

## Featured Projects
- **TaskFlow ⚡**: A dark, sleek task management web application built with **Next.js 14, TypeScript, Supabase, and shadcn/ui**.
  - Multiple Task Lists (Work, Personal, Projects, etc.)
  - Rich Task Fields & Interactive Due Date Picker (calendar popup, time selection, visual disabled dates)
  - Drag & Drop Reordering powered by `@dnd-kit` & Calendar View
  - Multi-criteria Filtering, Search & Smart Sorting
  - Browser Push Notifications via Service Worker
  - User-defined color-coded categories & safe deletion confirmations
- **Multi-Format Log Analyzer**: High-throughput network log analysis CLI (Palo Alto, UniFi, WatchGuard, Cisco Meraki) benchmarked with 1M+ records in ~60s using Polars.
- **Port Scanner & Web Security Dashboard**: Concurrent TCP scanner (ThreadPoolExecutor) with a browser diagnostic UI exposing JSON endpoints.
- **Files Compressor with Encryption**: Cross-platform desktop utility with zlib level-9 compression and Fernet authenticated encryption (AES-128-CBC + HMAC-SHA256).

## Tech Stack
- **HTML5 & Vanilla CSS**: Semantic structure, custom design tokens, modern typography (`Space Grotesk`, `Plus Jakarta Sans`, `Fira Code`), glassmorphism, responsive cyber dark aesthetic.
- **Vanilla JavaScript**: Dynamic project filtering, interactive hero terminal simulator with clickable commands, copy-to-clipboard interactions, and scroll spy navigation.

## Repository Structure
- `index.html`: Portfolio main landing page
- `style.css`: Comprehensive responsive styles and theme variables
- `script.js`: Interactive features, dynamic project cards, and terminal simulation
