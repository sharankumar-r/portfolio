## 🛠️ My Featured Projects
- **TaskFlow ⚡** — A dark, sleek task management web app built with **Next.js 14, TypeScript, Supabase, and shadcn/ui**.
  - Multiple Task Lists (Work, Personal, Projects, etc.)
  - Rich task fields & interactive due date picker (calendar popup, time selection, disabled visual states)
  - Drag & drop reordering powered by `@dnd-kit` alongside an interactive calendar view
  - Smart full-text search, overdue/priority filters, and multi-criteria sorting
  - Browser push notifications via Service Worker
  - User-defined color-coded categories & safe deletion confirmation dialogs
- **Multi-Format Log Analyzer** — High-throughput Python CLI for network security log ingestion (Palo Alto, UniFi, WatchGuard, Cisco Meraki) benchmarked at 1M+ records in ~60s using Polars.
- **Port Scanner & Web Security Dashboard** — Concurrent TCP scanner using `ThreadPoolExecutor` paired with a browser diagnostic UI exposing lightweight JSON endpoints.
- **Files Compressor with Encryption** — Cross-platform desktop utility combining zlib level-9 compression with Fernet authenticated encryption (AES-128-CBC + HMAC-SHA256).
